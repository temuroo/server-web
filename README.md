# Курсовой проект: веб-приложение для ведения заметок

**Тема:** «Разработка веб-приложения для ведения заметок пользователя».

**Автор:** Логунов Тимур Андреевич  
**Группа:** 251-3210


## Что сказать на защите

Я разработал веб-приложение для ведения заметок пользователя. В проекте есть маршрутизация, контроллер, шаблоны, формы и хранение данных в JSON-файле. Пользователь может добавлять, просматривать, редактировать, удалять и фильтровать заметки по категориям. Интерфейс оформлен в современной тёмной теме.
