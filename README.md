# Курсовой проект: веб-приложение для ведения заметок

**Тема:** «Разработка веб-приложения для ведения заметок пользователя».

**Автор:** Логунов Тимур Андреевич  
**Группа:** 251-3210

## Что делает сайт

Пользователь может:

- просматривать список заметок;
- добавлять новую заметку;
- редактировать заметку;
- удалять заметку;
- фильтровать заметки по категории.

## Особенности проекта

- PHP без фреймворков;
- простая маршрутизация;
- контроллер и шаблоны;
- хранение данных в JSON-файле;
- современная тёмная тема;
- адаптивная вёрстка.

## Как запустить

Открой терминал в папке проекта и введи:

```bash
php -S localhost:8000 router.php
```

Потом открой в браузере:

```text
http://localhost:8000
```
